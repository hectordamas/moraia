
# MORAIA — E-COMMERCE / BRAND EXPERIENCE

Quiero desarrollar desde cero el sitio web oficial de **Moraia**, una marca femenina enfocada en productos de interés para mujeres.

Moraia no debe percibirse simplemente como una tienda de lencería o una tienda de productos de belleza. La visión de la marca es convertirse en un **universo de productos femeninos**, donde una mujer pueda encontrar diferentes productos para ella o para regalarle a otra mujer.

La propuesta diferencial de Moraia es la posibilidad de **combinar productos diferentes dentro de una misma compra y crear boxes/regalos personalizados**, convirtiendo el e-commerce en una experiencia de descubrimiento y regalo.

---
